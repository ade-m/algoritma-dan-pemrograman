# Algoritma dan Pemrograman

Repository materi dan notebook untuk mata kuliah **Algoritma dan Pemrograman**.

## Struktur

- `06 - Binary Search/`
  - `Binary_Search_Deep_Dive.ipynb` — pendalaman Binary Search, eksperimen kompleksitas, studi kasus, dan challenge.

## Cara Menggunakan

Notebook dapat dibuka menggunakan:

- Jupyter Notebook / JupyterLab
- VS Code
- Google Colab

Materi Binary Search disusun sebagai *guided exploration* agar mahasiswa memahami bukan hanya cara implementasi, tetapi juga **kapan dan mengapa** Binary Search digunakan.
